# RemoteOK Job Scraper (Python + Selenium)

This project is a Python web scraper that collects remote developer job listings from [RemoteOK](https://remoteok.com/remote-dev-jobs) and exports them to a structured CSV file. It is designed as a reusable starting point for job market analysis, dashboards, and automation workflows. [file:57]

## Features

- Uses a real browser (Chrome + Selenium) to load the page like a human. [file:57]
- Extracts key business fields from each job:
  - Job title
  - Company name
  - Location
  - Salary (if available)
  - Direct job URL
- Supports simple pagination via a `pages_to_scrape` parameter.
- Saves results to a clean CSV file (`remote_jobs_selenium.csv`).

## Tech stack

- Python 3.x
- Selenium WebDriver
- `webdriver-manager` for automatic ChromeDriver management
